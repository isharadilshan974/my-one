MY ONE — FINAL
================

A polished local-first Streamlit Life Operating System.

RUN:
1. Install Python 3.10 or newer.
2. Extract this ZIP.
3. Double-click RUN_MY_ONE.bat.

OR from VS Code Terminal:
    python -m pip install -r requirements.txt
    python -m streamlit run app.py

DATA:
- All app data is stored in my_one_data.json beside app.py.
- Use Settings > Download MY ONE backup regularly.
- Settings > Restore can load a previous JSON backup.

SYSTEMS:
- Command Center
- Daily missions
- Habit streaks
- XP + levels
- Goals + roadmap
- Skill tree + career progression
- Money tracker
- Financial freedom framework
- Focus sessions
- Journal + wins
- Life analytics
- Achievements
- Profile / My Why
- Backup / restore
- Animated premium UI

IMPORTANT:
The financial section is for planning and education, not personalized financial advice.
The app does not promise wealth. It is designed to help you build consistent habits,
skills, career value, savings discipline and long-term resilience.
